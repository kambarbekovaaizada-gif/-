# Как опубликовать сайт «Медицинская физика»

Комплект подготовлен для репозитория:
https://github.com/kambarbekovaaizada-gif/Medical-Physics

Он содержит материалы занятий 1–8. Это файлы для публикации; их подготовка сама по себе не меняет сайт на GitHub.

## 1. Распакуйте архив

Извлеките файлы из `Medical_Physics_Publish.zip` на компьютер.

Главный файл должен называться **index.html** — без пробелов, номеров в скобках и дополнительного расширения `.txt`.

## 2. Загрузите файлы

1. Откройте репозиторий по ссылке выше и перейдите во вкладку **Code**.
2. Выберите **Add file → Upload files**.
3. Загрузите `index.html`, `README.md`, `PUBLISH.md` и `.nojekyll` в корень репозитория. Загружайте сами файлы, а не ZIP и не внешнюю папку комплекта.
4. Если в репозитории уже есть `index.html`, новая версия должна заменить его.
5. Подтвердите загрузку кнопкой **Commit changes** в выбранную ветку публикации.

`.nojekyll` — пустой файл, это нормально. Если система скрывает его или загрузка не добавила его в репозиторий, используйте **Add file → Create new file**, укажите имя `.nojekyll`, добавьте одну пустую строку и сохраните изменение.

Вкладка **Projects** предназначена для организации работы, а не для загрузки файлов сайта.

## 3. Настройте GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В блоке **Build and deployment** найдите **Source**.
3. Выберите **Deploy from a branch**.
4. В **Branch** выберите `main` (либо другую ветку, в которую загружены файлы).
5. Для папки выберите **/(root)**.
6. Нажмите **Save**.

Если Pages уже настроен на эту ветку и корневую папку, повторная настройка не требуется.

## 4. Откройте опубликованный сайт

Дождитесь успешного завершения публикации. Актуальную ссылку возьмите в **Settings → Pages**, кнопка **Visit site**. Статус и возможные ошибки доступны во вкладке **Actions**.

При стандартном домене проекта ожидаемый адрес:
https://kambarbekovaaizada-gif.github.io/Medical-Physics/

Этот адрес указан по стандартной схеме GitHub Pages; доступность опубликованного сайта в рамках подготовки комплекта не проверялась. Если настроен собственный домен, используйте адрес, который показывает GitHub.

## 5. Обновляйте сайт

После подготовки новых уроков загрузите новый `index.html` под тем же именем в ту же ветку и сохраните изменение. При публикации из ветки GitHub Pages использует изменения выбранного источника. Повторно создавать репозиторий не нужно.

## Если сайт не открывается

- Проверьте точное имя `index.html`: например, `index (9).html` не заменяет главную страницу.
- Убедитесь, что файл находится в корне ветки, выбранной в Pages.
- Проверьте, что источник — **Deploy from a branch**, ветка совпадает с местом загрузки, папка — **/(root)**.
- Посмотрите последнюю публикацию во вкладке **Actions** и её сообщения об ошибках.
- Если загрузка прошла успешно, но видна старая версия, обновите страницу с очисткой кэша: **Ctrl+F5**.
- Если настройки Pages недоступны, проверьте права на репозиторий и доступность Pages для его типа и вашего плана GitHub.
