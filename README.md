# Медицинская физика · Элективный курс

Учебный сайт элективного курса «Медицинская физика» для учащихся 10–11 классов.

**Автор:** PhD-докторант Камбарбекова А.А.  
**Организация:** Южно-Казахстанский педагогический университет имени Өзбекәлі Жәнібеков.

## Содержание

Программа рассчитана на 34 академических часа. В этой версии доступны 8 занятий:

1. Введение в медицинскую физику.
2. Развитие медицинской физики и современные медицинские технологии.
3. Давление и его измерение в медицине.
4. Физические основы кровотока и закон Бернулли.
5. Вязкость жидкостей и медицинские технологии.
6. Газовые законы и дыхательная техника.
7. Аппараты искусственной вентиляции лёгких (ИВЛ).
8. Звуковые волны и их свойства.

В каждом доступном занятии есть теория, иллюстрации, тест, расчётные задачи, жизненная ситуация и виртуальный эксперимент. Остальные темы отмечены как готовящиеся.

## Возможности

- Крупный шрифт и адаптивная вёрстка.
- Переключатель ҚАЗ / РУС / ENG: навигация и программа курса доступны на трёх языках; полный текст уроков пока на русском.
- Интерактивные модели по темам занятий.
- Правильные ответы открываются после отправки; отправленные ответы блокируются для редактирования в текущем браузере.
- Числовые ответы проверяются программно; развёрнутые ответы сравниваются с образцом самостоятельно.

Ответы, прогресс и язык сохраняются локально в браузере. Учётных записей, централизованного журнала оценок, отправки результатов учителю и подключения к ИИ-сервису нет. Очистка данных браузера или переход на другое устройство не сохраняют прежнюю попытку.

## Публикация

Загрузите содержимое комплекта в корень репозитория `Medical-Physics`. В разделе **Settings → Pages** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните настройки. Если основная ветка называется иначе, выберите её.

Подробная инструкция: [PUBLISH.md](PUBLISH.md).

## Обновление занятий

Заменяйте `index.html` новым согласованным файлом с тем же именем. Все изображения и данные уже встроены в HTML; дополнительные папки не нужны. Не заменяйте актуальный файл более ранней копией с меньшим количеством уроков.

При изменении самих заданий разработчику необходимо менять идентификаторы сохранённых попыток: иначе браузер может показывать ответы, отправленные для предыдущей редакции.

## Назначение моделей

Материалы предназначены для обучения физике. Модели являются упрощениями и не предназначены для медицинской диагностики, выбора лечения или настройки реального медицинского оборудования.
